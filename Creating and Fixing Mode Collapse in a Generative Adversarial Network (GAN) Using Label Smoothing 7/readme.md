This experiment demonstrated how mode collapse can occur in a Deep Convolutional Generative Adversarial Network (DCGAN) when training becomes unstable. Removing batch normalization, reducing generator capacity, and using a high learning rate can negatively affect training stability and the diversity of generated images. Label smoothing was applied to the improved model by changing the real-image target label from 1.0 to 0.9. The experiment highlights how label smoothing, along with a more stable model configuration, can help improve GAN training and generate more diverse and recognizable handwritten digits.
