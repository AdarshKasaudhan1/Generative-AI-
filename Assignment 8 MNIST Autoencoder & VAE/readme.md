A deep learning project that implements a Variational Autoencoder (VAE) using TensorFlow/Keras to learn a structured 2D latent space from the MNIST handwritten digit dataset. The project demonstrates image reconstruction, latent space visualization, and generation of new digits through smooth latent interpolation.


Features

MNIST handwritten digit dataset

GPU-enabled TensorFlow training

2D latent space representation

Variational Autoencoder (VAE) architecture

Reconstruction & KL Divergence loss tracking

20-epoch model training

Latent space scatter plot (colored by digit labels)

Original vs reconstructed image comparison

Digit generation across the latent space
